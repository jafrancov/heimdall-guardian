# Código de conducta

[Read in English → CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

Este proyecto sigue el **Contributor Covenant, versión 2.1**. El texto completo está en
<https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/>.

En resumen: sé respetuoso, da la bienvenida a personas de cualquier origen y nivel de
experiencia, da y recibe críticas constructivas con buena actitud y piensa en lo mejor para
la comunidad. No se aceptan el acoso, los ataques personales ni el lenguaje discriminatorio.

Para reportar un problema, escribe al mantenedor, Alejandro Franco, desde su perfil de GitHub
([@jafrancov](https://github.com/jafrancov)). Los reportes se atienden con discreción.
Las vulnerabilidades del software siguen [SECURITY.es.md](SECURITY.es.md).

Atribución: el Contributor Covenant se publica bajo
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.es) y está disponible en
<https://www.contributor-covenant.org/es/version/2/1/code_of_conduct.html>. Este archivo lo
referencia y no lo copia.
