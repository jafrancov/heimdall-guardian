# Contributing

Thank you for wanting to improve Heimdall Guardian. The full guide is
[CONTRIBUTING.md](https://github.com/jafrancov/heimdall-guardian/blob/main/CONTRIBUTING.md)
in the repository. In short:

- Read the six non-negotiable principles first: a change that violates one is rejected.
- A new rule is one YAML file in `rules/heimdall/<stack>/`, with English and Spanish texts,
  positive and negative fixtures and an exact expected count.
- Visible text goes in both language catalogs.
- Get `pre-commit run --all-files` green before sending your change.
- Add yourself to
  [CONTRIBUTORS.md](https://github.com/jafrancov/heimdall-guardian/blob/main/CONTRIBUTORS.md)
  in the same pull request.

## Building this site

The documentation uses MkDocs Material. Its tools live in the `docs` dependency group:

```bash
make docs         # regenerates the generated pages and builds the site strictly
make docs-serve   # live preview
```

The rules catalog, the OWASP page, the stacks page and the CLI reference are generated by
`tools/build_rule_docs.py` from the rule files and the code. Do not edit them by hand: a
test fails if the versioned pages are out of date.

To report a vulnerability, follow
[SECURITY.md](https://github.com/jafrancov/heimdall-guardian/blob/main/SECURITY.md).
