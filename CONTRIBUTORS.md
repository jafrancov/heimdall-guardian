## How to appear in this list

Any accepted contribution counts, not only code:

- code and tests,
- new or improved rules (see [CONTRIBUTING.md](CONTRIBUTING.md)),
- translations and wording fixes,
- documentation,
- reports of false positives with a minimal snippet that reproduces them,
- bug reports that lead to a fix.

Add yourself in the same pull request as your contribution (maintainers can also add you
afterwards). Keep the list in alphabetical order by name, one line per person:

```markdown
- **Your Name** ([@github-user](https://github.com/github-user)): rules, documentation
```

The part after the colon is a short list of what you contributed. The name and link are
public: add only what you are comfortable sharing.

The complete list, including people who prefer not to be named here, is also in the
[GitHub contributors graph](https://github.com/jafrancov/heimdall-guardian/graphs/contributors).
No external service or bot maintains this file; an all-contributors bot could be added
in the future.
